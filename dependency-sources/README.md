# Dependency source inputs

These upstream sources match the source hashes recorded by the installed vcpkg packages.
The exact vcpkg recipes and patches are in tools/dependency-recipes at the source root.
Apply a recipe's patches in its declared order when building a library manually.
The standard build uses the pinned vcpkg baseline in vcpkg.json; see the root README.md.
Original license notices are preserved. No dependency plugin DLLs are included.
