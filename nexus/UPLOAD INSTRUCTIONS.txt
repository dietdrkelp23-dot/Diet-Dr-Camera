DIET DR CAMERA 1.0.0 - NEXUS UPLOAD DIRECTIONS

Use the ZIP in Desktop/Diet Dr Camera - Mod as the main download and the ZIP in
Desktop/Diet Dr Camera - Source as the source download on the same mod page.
Desktop/Diet Dr Camera - Credits and Requirements.txt is ready to copy and paste.
Upload the ZIPs directly; do not ZIP either desktop folder again.

1. REVIEW GAMEPLAY ACCEPTANCE

The tested build is installed in the enabled MO2 mod Diet Dr Camera-1.0.0.
Mysticism projectile tracing, staff Ritual selection, Vanity, first-person
Hit Shake and the reported chained Whirlwind Sprint/Flee Framing retest have
author acceptance on Skyrim 1.6.1170.
Check RELEASE-CHECKLIST.md in the source archive for the other gameplay items,
including broader Flee Framing combinations, preset persistence, menus and the
earlier movement-stall scenario. Enable Verbose Logging for a detailed diagnostic
capture if needed; normal play leaves it off.
Only describe runtimes as tested after actually testing them. RUNTIME-SUPPORT.md
lists implemented targets and the existing evidence.

2. CREATE OR EDIT THE MOD PAGE

Sign in to Nexus Mods, select Skyrim Special Edition, and choose Upload a mod.
If your draft page already exists, edit that page instead of making a duplicate.
Use Diet Dr Camera as the name and 1.0.0 as the version. Choose the appropriate
camera/gameplay category. Keep the page unpublished while filling it out.

Paste Description - Nexus BBCode.txt into the description's BBCode/source editor.
This contains the overview, installation, requirements, compatibility, source
notice and credits. Separate Requirements and Full Credits text files are also
provided if you want to arrange those sections yourself. Use the plain-text copies
in fields that do not accept BBCode.

3. ENTER REQUIREMENTS

Add these Nexus mod requirements using their mod IDs or URLs:
  Address Library for SKSE Plugins - 32444
  SKSE Menu Framework 3 - 120352
  ImGui Icons - 114790 (framework gamepad-prompt requirement)

Include SKSE64 and Microsoft Visual C++ x64 Redistributable as external
requirements, with the links in Requirements.txt. Emphasize that SKSE, Address
Library and the framework must match the user's executable version.

True Directional Movement (51614) and Open Animation Replacer (92109) are optional
integrations. Describe them as optional; do not mark them as mandatory downloads.
Do not add CommonLibSSE-NG or the compiled C++ libraries as player requirements.

4. ADD THE FILES

MAIN FILE
  Upload: Diet Dr Camera-1.0.0.zip
  Display name: Diet Dr Camera
  Version: 1.0.0
  Category: Main files

SOURCE FILE
  Upload: Diet Dr Camera - Source-1.0.0.zip
  Display name: Diet Dr Camera - Source
  Version: 1.0.0
  Category: Miscellaneous files
  Description: Corresponding GPL source for Diet Dr Camera 1.0.0, including
  dependency sources, exact build recipes/patches, tests and build instructions.
  For developers; not required for playing. Do not install this ZIP in MO2/Vortex.
  Use manual download only if the form offers a mod-manager download setting.

Keep both downloads publicly accessible together. No separate GitHub repository
is required for this release. SHA256SUMS.txt and manifest.json are your verification
records; they do not need their own Nexus download entries.

5. SET CREDITS AND PERMISSIONS

Paste Full Credits.txt into the credits field, or use the BBCode copy if supported.
Paste Permissions.txt into the additional permissions/license notes field.

Where Nexus provides individual permission options, allow redistribution,
modification, conversion and asset/code reuse subject to the included GPL and
third-party terms. Do not require people to ask permission for GPL-permitted use.
Do not add a blanket ban on reuploads, commercial use or donation-point use of
GPL-covered code. Preserve the source-sharing and license-notice obligations.
For the ownership question, state that the release includes third-party open-source
components used under their licenses. Do not claim every component is your own.
These permissions do not change separate third-party terms or game asset rights.

6. ADD THE IMAGES

Select your preferred thumbnail and add gameplay screenshots/video if desired.
Preview the thumbnail crop and description formatting before publishing.

7. PREVIEW AND PUBLISH

Confirm that the main file is the installable ZIP, the matching source file is
available, the requirements/credits/license text is present, and all links work.
Review RELEASE-NOTES.md and the unchecked gameplay items in RELEASE-CHECKLIST.md.
Publish when you accept the tested behavior and the documented runtime coverage.

FOR FUTURE UPDATES

Increase the version, build/package again, and upload the matching new main and
source ZIPs together. Keep matching source access for older DLLs still offered.
Use the release packager; never package your live MO2 folder or personal presets.
Preserve the public preset format contract and frozen defaults in PRESET-COMPAT.md.
Preset creators should distribute their own TOML presets, not a copy of your DLL.
